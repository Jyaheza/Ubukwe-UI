# Ubukwe-UI 🎊

Ubukwe-UI is a modern, responsive React frontend for a wedding planning platform. It helps users browse and book wedding vendors, venues, and services with a clean and intuitive interface.

## 🖥️ Tech Stack

- **React** (with Hooks)
- **TypeScript** (optional if used)
- **Material-UI** (MUI) for styling and components
- **React Router** for navigation

## 📦 Installation

```bash
git clone <repo_url>
cd Ubukwe-UI
npm install
```
## Running the App
```bash
npm start
```
This will run the app locally at http://localhost:3000.

🧪 Running Tests
```bash
npm test
